钉铛智造 MES/ERP 系统页面结构与功能说明文档
测试环境：test3-workorder.daxiongplus.com账号：100004 / lxm111　　编制日期：2026-09-01
一、系统概述
钉铛智造是一套面向离散制造企业的一体化 MES + ERP 系统，覆盖“销售—采购—生产—委外—库存—质量—财务—人事—设备—项目”全业务链条，采用 B/S 架构、Vue 单页应用（SPA）+ 多页签工作区模式。系统左侧为一级业务导航，主区域以列表、单据表单、详情、看板/报表四类页面承载业务，支持多窗口并行操作。
本次共梳理一级菜单 21 项（其中 14 个为带子菜单的业务模块、7 个为直达页面/入口），二级功能页面约 300 个。下文先说明整体界面框架与通用页面模式，再逐模块给出页面清单（含路由、主要操作、表格规模），最后对生产工单等重点模块做功能布局详述。
二、整体界面布局与交互机制
2.1 页面框架（四区结构）
区域 | 位置 | 内容与作用
① 顶部栏 | 页面最上方 | 企业 Logo/名称、全局菜单搜索框（“请输入菜单名称”可快速定位功能）、行业必读、新手引导、企业ID与当前用户（测试员工）。
② 左侧导航 | 页面左侧 | 21 个一级菜单；点击直达页面或悬停展开“分组—功能页”二级浮层。
③ 页签栏 | 导航下方 | 已打开页面以页签形式保留，可多窗口并行切换；固定页签为“系统架构/驾驶舱”，普通页签可单独关闭。
④ 主内容区 | 右侧主体 | 承载列表、表单、详情、看板、报表等具体业务页面。
【重要机制】多页签上限为 20 个：当打开页面超过 20 个时，系统弹出“窗口数量不能超过20个，请关掉部分再打开”，并阻止打开新页面，需关闭部分页签后再操作。
2.2 五类通用页面模式
页面模式 | 典型特征 | 代表页面
列表查询页 | 顶部状态页签(可选)+筛选区（可“展开/收起”更多条件，含近3/7/15/30/60天快捷）+操作工具栏+数据表格（支持“列表字段”自定义显隐与列宽）+合计行+分页器 | 生产工单、销售订单、物料库存等绝大多数业务单据/档案
单据新增/编辑页 | 顶部“取消/保存/提交”，主体为多个折叠分区（基础/收货/财务等）+明细子表（产品列表/物料列表），支持选择产品、历史价格、附件上传 | 新增生产工单、新增销售订单
详情页 | 顶部业务操作按钮+基础资料只读区+明细/物料BOM+多个业务记录Tab（报工记录/关联单据/工序信息/操作记录等） | 生产工单详情
左树右表档案页 | 左侧分类树（支持新增/导入分类）+右侧档案列表（固定列+横向滚动列） | 物料档案、产品管理、供应商、设备/工模具
看板/报表页 | KPI 指标卡+ECharts 图表（趋势/排行/占比），或多维度筛选+导出报表；车间报工为全屏无菜单模式 | 驾驶舱、各类看板、生产/销售/财务报表、简易报工
2.3 单据通用生命周期
业务单据普遍遵循统一状态流转：新增/草稿 → 提交 → 审核（可反审核回退）→ 执行/入库/完工 → 完成；异常可作废、删除、撤回。工具栏与行内操作随单据状态动态启用/禁用（未勾选记录时，批量类按钮置灰）。多数单据支持导入、导出、打印（含批量打印/合并打印）、附件、审批流程与审批记录查看。

五、重点模块功能布局详述
5.1 首页 · 系统架构
首页为“系统架构一览图”，以流程箭头串联六大业务域，帮助用户理解业务闭环：
基础配置：角色用户管理、物料管理、工艺路线、产品管理、标准BOM、编码规则、图纸管理、不良品项、工序管理、仓库管理、序列号管理、客户价格资料；
销售：客户管理→报价→销售单/合同→订单BOM→设计中心→销售出库/送货→售后、退货、退款、发票；
采购：MRP计划→供应商→采购订单→采购审批→质检收货→采购核销/退货；
生产：主生产计划→生产计划→生产工单→生产领料→工序执行→成品（含委外生产）；
库管：物料入库、库存调拨、库存预警、成品入库、出库、库存盘点；
财务：总账、报表、应收/预收、应付/预付、现金银行、发票、工资、固定资产。
5.2 驾驶舱（经营数据看板）
驾驶舱以卡片+图表方式集中呈现经营全貌，自上而下、自左向右包含：
数据概览 KPI 行：销售订单准时率、工单生产准时率、销售订单总金额、生产总产值、采购订单总金额、应付/已付金额、库存周转率、物料库存金额、成品库存金额；
快捷菜单区（可配置常用功能入口）；
待办中心：按 销售/BOM/采购/生产/外协/库存/质量/财务/项目/人事 分类页签展示待审单据（待审销售单、待确认BOM、待审采购单、待审入库单等）；
销售/采购实时数据：按“本日/本月”切换，统计订单、出库/入库、退货单数与金额、新增客户/供应商；
图表区：销售趋势、净利润趋势与结构、产品汇总统计TOP8、工单统计、物料/产品库存情况；在制工单以卡片展示工序进度与是否延期。共约10个图表，支持“配置驾驶舱”自定义。
5.3 生产工单（核心模块，重点）
生产工单是生产执行的核心单据，菜单路径：生产管理 → 生产单据 → 生产工单，路由 #/production/workOrder。
(1) 列表页布局
状态页签：全部工单、未开始、执行中、快逾期、已逾期、已完成、已作废，共7个，点击即按状态过滤；
筛选区：默认显示“工单编号、产品编号/名称”，点“展开”后含产品规格、产品属性、生产类型、源单编号、外协状态、计划时间范围、质检状态、工序/工序状态、紧急状态、客户名称/编码、机台状态、客户交期、客户订单编号、入库状态、创建人、备注、更新时间、完工状态、负责人、产品分类、制单日期、自选产品等 25+ 条件，支持搜索/重置与近N天快捷；
工具栏：新增工单、导出、批量打印工艺流转卡、合并打印工艺流转卡、批量领料、批量开始/删除/结束/完工、开启、查看进度、列表字段（未勾选记录时批量按钮置灰）；
数据表格：35 列，含工单编号、工单状态、产品名称/编码/规格、客户信息、客户订单编号、入库状态、计划数/基本数量/已入库数量、生产/外协工序数、外协状态、客户交期、计划开始/结束时间、机台状态、制单日期、质检状态、负责人、领料状态、完工状态/时间、创建人/时间、更新人/时间、备注、操作；底部带数量合计行与分页器（当前共324条、33页）。
(2) 行内操作随状态变化（状态—操作矩阵）

六、端到端业务主流程
① 销售到生产主线：客户/线索 → 报价单 → 合同/销售订单 → 订单BOM/设计中心 →（MRP计划/主生产计划）→ 生产排产/生产工单 → 领料 → 工序报工/审工（可委外外协）→ 完工 → 产品入库 → 销售出库/送货 → 发票/核销/收款。
② 采购到付款主线：采购申请/询价 → 采购订单 → 到货检验（来料质检）→ 物料入库 → 采购发票 → 采购核销 → 付款；异常走采购退货/退款。
③ 委外加工主线：整单外协/工序外协 → 外协领料 → 外协检验 → 外协入库 → 外协成本核算与对账。
④ 库存与财务闭环：出入库流水 → 出库成本核算/业务关账结账 → 生成凭证 → 总账/报表（利润表、资产负债表、现金流量表）→ 应收应付与现金银行。

7.3 通用组件规范
(1) 状态页签 Tabs
位于列表顶部，横向胶囊/下划线式；未选中黑字，选中项为红底白字或红字红边框（如生产工单7状态Tab）；点击即带状态条件查询并刷新表格。
(2) 筛选区 FilterForm
el-form inline 布局，输入框高30px、直角；常用条件常驻，点“展开/收起”切换更多条件；右侧固定“搜索(主色)、重置(描边)”；部分日期字段带“近3/7/15/30/60天”快捷按钮。
(3) 操作工具栏 Toolbar
位于筛选区下方、表格上方，左对齐排列按钮：主操作（新增，红底白字）+ 次操作（导出、批量动作，白底灰边）；依赖勾选行的批量按钮在未勾选时 disabled 置灰；右侧常有“列表字段”自定义显隐列。
(4) 数据表格 Table
el-table，表头白底、40px高、字重600；支持固定首列/操作列、横向滚动、行尾“操作”列放文字按钮（编辑/详情/删除等，红字）；编号类单元格悬浮出省略提示；底部左侧为“合计”行（数值列求和），右侧为分页器（总数、页码、每页条数、前往N页）。
(5) 状态标签 Tag
用不同颜色 el-tag 表达状态：未开始/草稿=灰(info)、执行中=蓝或主色、已完成/合格=绿(success)、预警/快逾期=橙(warning)、已逾期/已作废=红(danger)。
(6) 表单 Form / 弹窗
label 右对齐、必填项前红色*；控件含 input/select/date-picker/textarea(带0/N字数统计)/upload(附件)/switch；复杂单据用折叠面板(el-collapse)分“基础信息/收货/财务”等区；新增/编辑多为整页路由，少量为 el-dialog 弹窗或 el-drawer 抽屉；删除、作废、反审核等危险动作先弹 ElMessageBox 二次确认。
(7) 反馈与审批
操作成功/失败用右上角 ElMessage 轻提示；单据可“查看审批流程/审批记录”；提交后进入待审核，审核/反审核改变状态与可用按钮。

8.3 路由与页面清单
系统采用 hash 路由（#/模块/页面，列表→新增/详情为同级 add/detail，如 #/production/workOrder、/add、/detail?id=）。全部约415个页面的“名称—路由—操作—规模”已在第四章逐模块列出，可直接作为前端路由表与菜单表的数据源。
九、给前端 / AI 的实现指引
技术栈：Vue3 + Vite + Element Plus + Vue-Router(hash) + Pinia + ECharts + axios；UI 以 Element 组件为主体，主色覆盖为 #C00000。
目录建议：layout(顶部/侧栏/页签)、components(ProTable 高级表格、SearchForm 筛选、StatusTag、PageCrud)、views(按14模块建目录)、router(由菜单数据动态生成)、store(tagsView 多页签、user、dict)、api、utils。
抽象一个 ProTable 页面骨架：状态Tabs + SearchForm(展开收起) + Toolbar(批量按钮联动勾选) + el-table(固定列/列表字段/合计) + 分页；90%列表页用同一骨架，传入 columns 与 actions 配置即可生成。
抽象一个 CrudForm：用 schema 数组描述字段（name/label/type/required/options/api/规则），自动渲染控件、校验与折叠分区；明细子表用可编辑 el-table。
多页签：路由变化时在 tagsView 增加页签并 keep-alive 缓存组件，超过20个拦截提示；固定“系统架构/驾驶舱”。
权限/状态驱动按钮：按单据状态返回可用 action 列表（见状态矩阵），前端用 v-if 控制行按钮与批量按钮禁用。
Mock：可先用第四章页面清单与第八节字典构造 mock 数据（工单/订单各造20条覆盖各状态），即可独立跑通界面。
可直接投喂给 AI 的生成提示词：
请用 Vue3 + Element Plus 实现一个“生产工单列表”页：顶部7个状态Tab(全部/未开始/执行中/快逾期/已逾期/已完成/已作废, 选中#C00000)；
其下可展开筛选表单(工单编号、产品名称等, 搜索/重置)；工具栏含新增工单(主色)、导出、批量按钮(未勾选禁用)、列表字段；
主体为带复选框、固定首尾列、可横滚的 el-table，列按文档7.5的35列，状态用彩色 el-tag，行尾操作列按“状态-操作矩阵”显示文字按钮；
底部为合计行+分页(总数/页码/跳页)。微软雅黑14px、输入框30px直角、按钮32px圆角8px、页面灰底#F8F7F7卡片白底。配套20条mock数据。
