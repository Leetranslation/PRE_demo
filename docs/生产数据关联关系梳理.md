## 三、关联现状详细说明

### 3.1 已打通的关联（✅）

| 关联 | 说明 |
|---|---|
| 工艺路线 → 工序 | `process_route_item.process_id` 已正确引用 `process` 表 ✅ |
| 机台 → 车间 | `machine.workshop_id` 已正确引用 `workshop` 表 ✅ |

### 3.2 半断裂的关联（⚠️ 有数据但没连上）

**① BOM 明细的工序是字符串，不是外键**

当前 `bom_item.process` 是 `VARCHAR`，自由填写工序名（如"切割"），没有引用 `process` 表的 ID。

- 问题：BOM 里写的工序名，和「工序管理」里建的工序对不上，无法联动
- 影响：工艺路线（产品→工序序列）和 BOM（产品→物料+工序）两套体系各说各话
- 建议：`bom_item` 增加 `process_id` 字段引用 `process` 表（`process` 字符串保留做兼容或废弃）

**② 物料/产品的单位是字符串，不是外键**

当前 `material.unit`、`product.unit` 是 `VARCHAR`，自由填"个/公斤"。

- 问题：和「单位管理」`unit` 表、"多单位转换率" `unit_conversion` 表脱节
- 影响：多单位换算、单位统一管理无法落地
- 建议：物料/产品增加 `unit_id` 引用 `unit` 表（或至少让单位下拉来自 `unit` 表）

**③ 库区没有和库位/库存建立层级**

当前仓库层级是：`warehouse`（仓库）→ `location`（库位）。新加的 `area`（库区）是中间层，但：

- `location` 表只有 `warehouse_id`，没有 `area_id`
- 库存台账 `inventory.location_id` 只到库位，不知道库位属于哪个库区
- 建议：明确层级「仓库 → 库区 → 库位」，`location` 加 `area_id`；或确认库区与库位是平级关系（二选一）

**④ 序列号规则没有被物料/产品引用**

`material.batch_manage` 支持 `serial`（序列号管理），但没有关联 `serial_rule` 规则表。

- 建议：物料启用序列号时，可选择一条 `serial_rule` 作为生成规则

### 3.3 完全断裂的关联（❌ 完全没有）

**⑤ 生产工单没有引用车间/机台/工艺路线**

当前 `production_order` 表字段：`product_id / quantity / production_type / plan_date / source_type / source_id / plan_finish_date / department_id / owner / bom_id / bom_version_id / approve_status / biz_status / completed_qty / remark`

缺失：`workshop_id`（车间）、`machine_id`（机台）、`process_route_id`（工艺路线）

- 问题：生产数据里建的车间/机台，生产工单下单时选不到，关联断链
- 建议：工单增加这三个字段，新增表单加车间/机台下拉（机台按车间过滤），选产品自动带工艺路线

### 3.4 待建的关联（🔜 阶段 2 才有）

以下关联依赖阶段 2 的 MES 执行模块（报工/审工/排产），当前业务模块还不存在，无需现在打通，但需在阶段 2 设计时预留：

| 基础数据 | 阶段2模块 | 关联点 |
|---|---|---|
| 车间/机台 | 报工管理 | 报工单按车间/机台记录 |
| 工序/工艺路线 | 报工管理 | 工单→工艺路线→工序展开报工 |
| 工作日历 | 排产计划 | 排产按工作日倒推交期 |
| 机台 | 排产计划 | 机台产能负载 |

## 四、建议的打通顺序

### 第一批（本次，打通核心主线，验证关联机制）✅ 已完成

1. **生产工单 + 车间**：工单表加 `workshop_id`，表单加车间下拉，列表显示车间 ✅
2. **生产工单 + 机台**：工单表加 `machine_id`，选车间后机台下拉联动过滤 ✅
3. **生产工单 + 工艺路线**：选产品后自动带出该产品的工艺路线（复用现有自动带 BOM 的逻辑）✅

> 已验证：建车间→建机台（关联车间）→建工艺路线（关联产品）→创建工单（选车间/机台）→工单正确记录车间/机台ID→选产品自动带出工艺路线。测试通过。

### 第二批（阶段 2 前，修正半断裂）

4. **BOM 明细 + 工序**：`bom_item` 加 `process_id`

6. **库区 + 库位**：明确层级，`location` 加 `area_id`（或确认平级）
